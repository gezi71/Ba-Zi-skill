# 子平月令候选：规则、出处与边界

主线是月令格局，扶抑与调候作补充。本引擎只计算结构候选，未自动判断完整成格、
破格、救应或喜忌用神。`强弱启发式`不是本书取用法，不能直接换成用神。
规则版本：`ziping-candidates-1`；代码：`bazi/patterns.py`。

均是另一层文本，不当成沈氏原文，也不从古文直接推出个人预测。

  比劫月需要另看其他干支，不以日主自身当作普通财官印食取用。
- [《论用神变化》](https://donglishuzhai.net/chapter/3723.html)：透干、会支可改变结构，

- [《论杂气如何取用》](https://www.donglishuzhai.net/chapter/3729.html)：兼透、透会并存

- [《论用神成败救应》](https://donglishuzhai.net/chapter/3722.html)：成立还涉及根、
  强弱、位置、制化及救应，十神同见不足以证明成立。
- [《论刑冲会合解法》](https://donglishuzhai.net/chapter/3720.html)：会合与冲可并存，
  不能自动删掉相冲。原文所称申子辰“三会”对应本仓库的“三合支组”，不是寅卯辰方局。

## 第一版可核对的规则

| 规则 | 命中条件 | 不满足或反例 | 输出边界 |
| --- | --- | --- | --- |
| 月令候选 | 月支藏干相对日主为官、杀、财、印、食、伤 | 年干有正官而月令不藏该干，不能因此造一个月令正官候选 | 逐个保留，正偏有别，未确定主格 |
| 同干透出 | 月藏干与年/月/时干完全相同 | 月藏甲而天干只有乙，不算甲透；日干不当作所取之神透出 | 记录柱位；不透仍是月令因素，非“无格” |
| 比劫月 | 月本气相对日主为比肩/劫财 | 不能把余气透出就称普通八格已成；阴干比劫月不自动套五阳刃 | 明确普通八格取用未覆盖，另查建禄月劫/阳刃原文 |
| 四墓月 | 月支为辰戌丑未 | 月本气顺序或单一权重不能决定杂气主格 | 保留兼透、会支与未评估限制 |
| 六冲、六合 | 柱位所含地支命中既有对照表 | 同支重复不是六合；命中六合不能删掉其他相冲 | 每个关系保留位置，不判解冲 |
| 完整三合支组 | 申子辰/亥卯未/寅午戌/巳酉丑三支齐全 | 只有两支不输出完整三合；重复一支不补齐第三支 | 只报告支组齐全，不断合化 |

规则没有优先排除未透候选，也未从启发式评分判断成格。来源中的特殊情形
不能被省略成简化口诀。例如辛寅甲丙兼透，原文有本格与兼格之分，脚本应同时列线索。

## 十神组合与反证线索

当前只输出年、月、时天干上的官印相生、食伤生财、食神制杀**同见线索**。
暗藏不透的组合未自动识别；没有线索不代表该结构绝不存在。

候选的反证线索来自《论用神成败救应》涉及的伤官、财、比劫、偏印等同见关系，
不是完整破格判定。例如：正官同见伤官仍须查印、财及位置救应；食神七杀同见
仍须看是否制得住及印财干扰，不能写“已制杀”。这些待核条件统一输出为 `未评估`。

扶抑只参考评分明细；调候需要核对原文、季节和完整条件，第一版没有自动调候规则。
遇到从格、化气或未覆盖的制化问题，明确“该判断尚未实现”，不能由模型补算。

## 解释示例

1990-06-15 北京 14:30、未回拨夏令时的代表盘，辛日主、午月：
月令午藏丁为七杀、己为偏印；月干壬为伤官，伤官并非午月藏干。
脚本列七杀与偏印的月令候选，两干都未透；不能据此任选一个称“成格”。
若钟表读数需要回拨，时柱和相关结构可能变化，先比较情景再解释。

解释应写“月令有七杀因素，可作为外部要求这一传统象义的观察角度；
当前未判制化及成格”，而非“七杀格已成，所以事业一定如此”。
