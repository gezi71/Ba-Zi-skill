# 解读框架与话术规范

这篇规定「怎么把排盘数据讲成人话」。写得比较啰嗦，但每一条都有对应的失败案例。

## 一、解盘的标准顺序

拿到排盘输出后，以月令候选为主线组织判断：

1. **定日主** —— 日柱天干，五行属什么
2. **看月令** —— 日主在出生月的状态（旺/相/休/囚/死），这是全局最重的支点
3. **看月令格局候选** —— 读 `传统结构` 的条件、不满足项、反证线索和未评估项目；不把候选当成格
4. **看强弱明细** —— 扶抑作为补充，不从分数自动推出用神
5. **看十神结构** —— 透出哪几个、有无成组（如食伤生财、官印相生）
6. **看支藏** —— 天干是露出来的，地支藏干才是底子
7. **看神煞** —— 只作辅助，不单独断事
8. **叠大运流年** —— 现在是第几步运，今年流年是什么

## 二、四种该说的 vs 四种不该说的

| 该说 | 不该说 |
| --- | --- |
| 「五行偏枯，生活节奏上需要留意」 | 「你容易得肝病」 |
| 「可作为观察自己的一个角度」 | 「你一定会……」 |
| 「这一派认为 X，另一派认为 Y」 | 「自古以来都说 X」 |
| 「这个位置容易让人在 XX 上投入过多」 | 「XX 必定不顺」 |

## 三、硬性红线

这些不是风格偏好，是边界：

- **不做医疗判断。** 不得指向具体疾病、器官、症状。
- **不做财务的具体指令。** 不说买什么、什么时候买卖、投什么。
- **不虚构案例。** 不说「我见过一个和你同盘的人」。一旦说了，后面所有话都不可信。
- **不断生死、不说某人寿数。**
- **不用恐惧话术。** 「犯太岁」「血光之灾」「必有大难」一律不许。
- **不做法律/政策的实务判断**（如「官司必赢」）。
- **必须标明性质。** 自然带一句「命理属传统文化范畴，不具科学预测效力」。
  不要写成法务声明，融进叙述里即可。

## 四、分寸感：好解盘 vs 差解盘

### 差的例子

> 你的八字日主辛金，生于午月，火旺金死，身弱无疑。命中缺水，水主智，
> 主肾，所以你要注意肾脏。今年丙午流年，火更旺，必有灾，建议你今年不要投资，
> 农历五月尤其小心。

问题：把启发式说成了定论；做了医疗判断；用了恐惧话术；给了具体财务指令；
编了「农历五月」这种毫无依据的精度。

### 好的例子

> 日主辛金，生在午月 —— 火旺金死，启发式评分显示偏弱，不能据此认定格局或用神。
> 排盘给出的强弱评分是 -38.5 分，判为「身弱」。
> 这里要说明的是：这个分数是一套加权启发式，不是权威定式，
> 命理界对身强弱各家算法的分歧很大，看作一条线索就好。
>
> 落到具体结构上：以示例中未回拨的北京 14:30 盘为例，月干壬为伤官、时干乙为偏财，
> 年月两支午各藏丁七杀和己偏印。
> 七杀的传统象义可作为观察外部要求与产出期待的角度，不代表本人必然长期处于高压。
> 月干壬是伤官，可从表达、审美、批判性思维的传统象义观察；这不是月令藏干。
>
> 有一个值得注意的点：这十年走的是 XX 大运，大运天干对你而言是 XX，
> 和上面的结构叠在一起，效果是……

差别在于：**同样的数据，一个给判决书，一个给镜子。**

## 五、强弱那个分数怎么用

脚本输出的「身强/身弱」是启发式（详见 README §5.5）。用它的正确方式：

- **讲的时候要提它是启发式。** 一次性的自然交代，不要反复免责。
- **看明细比看结论重要。** 明细里写着「通根 +0.0 分」的盘，
  只说明本算法未找到同干藏根，不足以证明各流派都判身弱；如果明细里各项互相抵消，
  那就是个模棱两可的盘，实话说「处在中间地带」。
- **别把它当成行动指令。** 不需要说「你身弱所以要补金」。

## 六、告警必须先传达

检查 JSON 的 `告警`、候选组的 `告警` 及 stderr；有告警时**先说这个，再说别的**。
那是 Script 在告诉你这张盘可能有错。隐瞒它去解盘，
等于给用户一张可能错的盘还说得很笃定。

流程见 SKILL.md 第3节与 `uncertainty.md`。

## 七、输出形态

默认围绕用户问题回答，引用相关字段与规则条件。完整分析才使用 `assets/report_template.md`。
性别未知省略大运，未确认时间保留候选，流年按用户关心的年份。要点：

- 开头用一句话交代这是什么（不是科学性评估）
- 中段按「结构 → 倾向 → 当下」推进
- 结尾留出可操作的部分，而不是收结在命运判决上
- 不要复制排盘表格全部内容到报告里 —— 挑有用的讲，表格作为附录放在最后

## 八、核心判断的证据链

每个核心判断能回指“脚本字段 → 参考规则及成立条件 → 文化性倾向 → 不确定性”。
例如月干伤官、月令藏七杀是两个不同字段，不能混写为“月令伤官”。
引用古籍时标明篇名/规则链接；文化性行为解释是现代转述，不冒充古籍原句。
候选只提供线索，待核条件缺失时不定格、不取用神。完整规则边界见 `patterns.md`。

输出前核对：告警已传达；每个十神/位置来自脚本；候选未升格为定论；
没有无依据的概率；时间未确认时未擅自选盘；只回答用户需要的主题。
