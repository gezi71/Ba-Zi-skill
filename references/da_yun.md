# 大运与流年

> 一句话概括：**命局是车，大运是路，流年是天气。**

## 一、大运是怎么来的

大运不是从生日开始走的。它的起点由「出生时刻到最近一个节的距离」折算而来：

| 规则 | 内容 |
| --- | --- |
| 折算 | 三日为一岁，一日为四个月，一个时辰（2 小时）为十天 |
| 方向 | 阳年男、阴年女 → 顺行（用之后的那个节）<br>阴年男、阳年女 → 逆行（用之前的那个节） |
| 阳年 | 年干为甲丙戊庚壬 |
| 每步 | 10 年 |

举例：某人出生距下一个节 22.2 天 → 22.2 / 3 ≈ 7.4 岁起运，即约 7 岁 4 个月时进入第 1 步大运。
在起运前，尚未进入第一步大运；本脚本不计算小运/童限，不把月柱当成已计算出的运程。

脚本已经算好了这些，输出里的 `## 六、大运` 直接可用。

## 二、怎么讲大运

### 2.1 把大运干支当成「十年的环境色」

大运天干相对于日主的十神，说明了这十年外部环境的主题：

| 大运十神 | 十年主题（倾向） |
| --- | --- |
| 比劫 | 竞争加剧、同业关系凸显、需要自建边界 |
| 食伤 | 表达欲上升、想做自己的东西、也容易对现状不满 |
| 财星 | 资源与变现的机会变多，同时牵扯精力分配 |
| 官杀 | 外部要求变高，压力与名位同时到来 |
| 印星 | 学习、沉淀、得助的阶段，适合积累而非冲刺 |

### 2.2 看大运与原局的关系，而不是孤立看大运本身

关键三问：

1. **这个大运补上了日主缺的吗？** 身弱而原局无印，走到印运往往会明显好转。
2. **它冲了原局哪一柱？** 大运地支与原局某一支相冲，那一柱代表的人事容易起变化。
3. **它是顺着原局的格局还是逆着？** 原局财旺而身弱，再走财运，是「看得见抓不住」。

### 2.3 时间轴的诚实说明

起运日期依赖节气时刻。当前2024、2026样本最大差约13.8分钟，并非全年份上限。
按1小时折5天，15分钟约折1.25天；还受日期截断和流派口径影响。
涉及换运日期或年份交界时应保留候选范围，不能保证误差没有实际影响。
详见 [校准基准](calibration.md)。

## 三、流年

### 3.1 流年干支

流年 = 该年的干支，由 `(公历年 - 4) % 60` 得到。
严格按节气切分的话，同一公历年的 1–2 月属上一年干支 —— 本引擎取「整年」口径，
这也是排流年表的通行做法。

### 3.2 怎么讲流年

流年与大运、原局构成三层叠加。使用 JSON 的 `与原局冲合` 和 `大运叠加` 字段，
后者按起止日期列出该公历年内涉及的运；交运年可能有两步，不能只按整数年龄选运。
候选比较时还须检查各组的起运日期范围。关系同见不代表合化、解冲或必然事件。通常这样讲：

1. **流年天干的十神** → 这一年的主题倾向
2. **流年地支与原局是否有冲、合** → 哪一块会被触动（年柱=长辈/早年环境，
   月柱=手足/同辈/事业场域，日支=婚姻与自身，时柱=晚辈/输出/晚年）
3. **是否犯长期结构** → 例如身弱的年份又走耗身流年

### 3.3 不要做的事

- **不要说「今年必有灾」「必有血光」。** 断生死、断凶祸是被明令禁止的红线。
- **不要精确到月份给财务建议。** 不许说"三月适合买入"。
- **不要用太岁、犯冲制造恐惧。** 可以说「这一年外部变化会比较密集，
  适合把精力放在……」，但不能用恐吓式话术。

## 四、给用户的一段话该怎么组织

好的大运流年解读，通常是这个结构：

1. **先定位**：「你现在走的是第三步大运，X 运，大约 2017–2027 这十年」
2. **说这十年的主题**：「这步运的天干对你而言是 XX，十年里比较突出的主题是……」
3. **结合原局**：「和你原局里 XX 太重这一点叠在一起，效果会被放大/被缓解」
4. **给今年**：「今年是 X 年，对你而言是 XX，和上面的十年主题叠加后……」
5. **落到可操作**：「所以这一年对你来说，比起冲刺，更适合……」

避免：罗列每一年的干支然后每年写一句话。用户读不进去，也没有实际价值。

流年输出的“年份差”仅为流年年份减出生年份，不是虚岁或精确周岁。
