# 十神象义

十神是八字解读的骨架。它们由「日主与其他天干的生克关系」产生，
每一个既是人际关系，也是心理倾向，也是事件类型。

> 用法：排盘脚本已经算好了每一柱的十神。这一篇告诉你它们分别意味着什么，
> 怎么用这些词组织成一段有信息量的话。**不要背，引用。**

## 一、十神的生成规则

以日主（日柱天干）为「我」，看其他天干：

| 关系 | 同阴阳 | 异阴阳 |
| --- | --- | --- |
| 同我（同五行） | 比肩 | 劫财 |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 克我 | 七杀 | 正官 |
| 生我 | 偏印 | 正印 |

「同性为偏、异性为正」是通行写法。记忆要点：**先看是生是克，再看同不同阴阳。**

## 二、逐个十神

### 比肩
自我、独立、平辈、同僚、朋友。

正向：自尊自立的底色重，不轻附于人，能自己扛事。
隐患：与人相助的意识偏弱，合作中容易坚持己见。
组合注意：比肩过多而无官杀约束，表现为孤僻好争；有官杀则为「有担当的竞争者」。

### 劫财
比劫同气，但劫财带「争夺」色彩 —— 同辈、兄弟姐妹、合伙人，也指向破财。

正向：行动力强、能冲能抢、求财主动。
隐患：财来得快去得也快，合作易起纠纷。
组合注意：劫财重重而无食伤泄秀，多劳少获；有食伤通关则转化为执行力。

### 食神
我生者，且同性 —— 才华的自然流露、口福、技艺、温和的表达。

正向：有审美与技术直觉，表达不费力，心态松散而从容。
隐患：容易满足于现状，行动力偏软。
组合注意：食神与七杀同见只是“食神制杀”的待核线索；须结合月令、力量、根与印财干扰，不能认定已制杀。

### 伤官
我生者，异性 —— 才华的锋利面，反传统、善辩、自我意识强。

正向：创造力与批判性思维，不墨守成规，能看见别人看不见的角度。
隐患：与权威（正官）天然对立，容易对抗规则，口舌是非。
组合注意：伤官见官，古籍视为不吉，现代多理解为「挑战型人格」；
若有财星通关（伤官生财、财生官），则为「用才华换取资源与社会位阶」。

### 正财
我克者，异性 —— 通过稳定劳作换来的财富，也代表妻子（男命）。

正向：务实、守序、重视积累，财务上有纪律。
隐患：偏保守，容易把安全感绑定在具体资源上。
组合注意：正财怕比劫争夺；喜官星护之。

### 偏财
我克者，同性 —— 非固定收入、投资、意外之财、社交性资源，也代表父亲。

正向：善于发现机会，人脉广，对外的资源整合能力强。
隐患：来去都快，稳定性弱。
组合注意：偏旺而无制时散漫；有食伤生之则「以能力变现」。

### 正官
克我者，异性 —— 规则、名分、职位、丈夫（女命）。

正向：守规矩、有责任感、能进入秩序型组织并被认可。
隐患：压力大，容易为名位所累，畏首畏尾。
组合注意：官星宜有财生、有印护；官杀混杂则规则感混乱。

### 七杀（偏官）
克我者，同性 —— 压力、竞争、风险、魄力，也代表压迫性的人或环境。

正向：逆商高，危机中反而被激发，执行力凶悍。
隐患：长期高压，身心消耗大，易有冲突。
组合注意：七杀必须有制 —— 食神制杀、印星化杀、或身强可任，
三条路都没有则表现为被压力压垮。

### 正印
生我者，异性 —— 学识、庇护、长辈、文凭、体制的认可。

正向：好学、有涵养、易得贵人荫庇，抽象思维强。
隐患：依赖性强，容易活在观念里而疏于行动。
组合注意：印重身强而无泄者，书生气重；财星破印则失荫庇。

### 偏印（枭神）
生我者，同性 —— 冷门学问、直觉、另类思维、偏门技艺。

正向：联想能力强，能钻研非常规领域，独立思考。
隐患：孤僻、多疑，遇事容易往负面解释。
组合注意：偏印夺食（偏印与食神同见，食神受克）古籍认为有碍，
现代多理解为「思维过于批判而消耗了表达与创造」。

## 三、怎么把十神讲成人话

不要罗列「你有食神、有偏财」。要做的是：**挑出最突出的两三个，
讲它们之间的张力，落到具体行为模式上。**

例：

> 月干为伤官、时干为正财（假设已由脚本确认）。这个结构说的是：你的想法和批评能力很强，
> 但你真正能把话说出去的方式，是把它们换成别人看得见的价值。
> 换句话说，纯粹表达观点会让你碰壁，把它做成作品就不会。

落到十神之间的**关系**上，而不是单独描述每一个：

| 组合 | 可讲的角度 |
| --- | --- |
| 食神制杀 | 用才华与从容化解压力 |
| 伤官配印 | 锋利的表达有学养兜底 |
| 财官相生 | 资源与名分互相成就，适合走体制/组织路线 |
| 官印相生 | 得体制认可，靠资历与信用累积 |
| 食伤生财 | 把能力与审美变成收入 |
| 比劫夺财 | 合作与钱财上的边界问题 |
| 枭神夺食 | 思维过度内耗，消耗了表达欲 |

## 四、注意事项

- 十神没有绝对好坏。**七杀重而有制，往往比正官一片祥和更有成就张力。**
- 天干是「露出来的」，地支藏干是「真实的底子」。
  天干透出一个伤官、地支全无根，其力远小于天干不见而地支藏有力。
- 不要只数个数。十神的实际力量取决于通根、月令、相邻的生克制化。

格局主线及组合成立条件见 `patterns.md`；本篇的行为象义是文化性转述，不是自动定格规则。
