# 典籍目录与简体检索

本轮整理范围为现有月令候选、三类组合线索和调候查阅。数据在
`bazi/data/classical_rules.json`，保留原文、项目解释、后人注文、校对状态及简体章节索引。
没有后人注文的记录用 null，不能把项目解释冒充古籍注释。

| 书籍与版本 | 分工 | 校对进度 |
| --- | --- | --- |
| 子平真诠：NLC 世界图书馆影印；东里转录另据育新书局本 | 月令、变化、成败救应 | 相关章节已有影印核对记录，见 patterns.md；不等于全书校勘 |
| 渊海子平：NLC 文明书局合刊 | 藏干与口诀异文 | 已定位影印底本；维基文库页标记来源存疑及未完成，不采用其条文 |
| 三命通会：维基文库四库全书本 | 异说、命例背景 | 保存四库提要短摘录，仅作版本背景；不把命例当预测验证数据 |
| 滴天髓：维基文库辑要转录 | 旺衰、气势、寒暖 | 保存寒暖、月令短摘录，正文与所录注文分层，尚未校影 |
| 穷通宝鉴：维基文库转录；候选1926合刊影印 | 日干、节月调候查阅 | 三段短文已核在线转录，未校影；仅供查阅，不自动取用 |

底本链接、版本及每条出处在 JSON 中。待核查书籍不写成“已校勘全文”。
从来源下载时应保留版本或固定修订号；重新校对须更新状态和日期。

按问题读取对应条目：

```bash
python scripts/query_classics.py --query 成败
python scripts/query_classics.py --day-stem 甲 --month-branch 寅
```

调候索引覆盖十干、十二月支的章节定位，但目前只保存甲寅、甲子、己寅三个短摘录。
无匹配摘录时返回章节与明确限制，不生成喜用神。按寅为第一节月、丑为第十二节月
检索原书月份；不能拿出生农历月数代替月柱。全文上下文须另行核查。

## 已知差异与本项目选择

- 子平真诠影印本与东里育新书局转录并非同一版本。东里校记、山人按与沈氏正文分开。
- “三会”在该书相关段落指申子辰类支组，代码沿用“三合支组”；不据此新增方局规则。
- 该书月令取用与项目扶抑评分是两种方法。保留评分兼容性，不由它自动确认喜忌。
- 官印、食财同见需区分官格用印、印格用官、财逢食生及食神生财等月令主线。
- 藏干顺序及长生口径保留 decisions.md 现有选择；待逐项核查其他版本，不宣称各书完全一致。
- 穷通宝鉴网页底本未明确，且影印合刊目录不能代替对应卷正文校对。未影校摘录只供查阅。

允许有出处的规则事实与文化性观察；不把古籍的阶层、性别、疾病、寿夭断语转换为现代个人事实。

补充摘录也进入简体检索，但不进入可执行规则编号。搜索来源存疑的网页只能帮助定位，不能当作已校底本。
